# BLINKIT SALES ANALYSIS 
A visually interactive and insightful dashboard created in Power BI to analyze sales, outlet performance, and customer trends for Blinkit, a last-minute delivery app.  

## Features  

### Total Sales Analysis  
- Displays overall sales, average sales per item, and the number of items sold.  

### Outlet Performance  
- Breakdown by location (Tier 1, Tier 2, Tier 3).  
- Performance comparison by outlet size (Small, Medium, High).  
- Insights into outlet establishment trends over the years.  

### Item Analysis  
- Sales and ratings segmented by item type (e.g., Dairy, Snacks, Health, Frozen, etc.).  
- Analysis of fat content (Low Fat vs. Regular) across items and outlets.  

### Key Metrics  
- Average product ratings.  
- Total sales distribution and trends.  
- Item visibility and outlet efficiency.  

## Tools Used  
- **Power BI**: For data visualization and dashboard creation.  

## Learnings  
- Creating interactive dashboards using slicers and filters.  
- Designing visually appealing KPI cards for summary statistics.  
- Incorporating dynamic visuals, such as pie charts, bar graphs, and line charts.  
- Grouping data by multiple dimensions (e.g., location, outlet size, item type).  
- Analyzing trends over time with line and column visualizations.
